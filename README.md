## Dataset

This project uses transaction and store-level data from the Round Roasters market test, originally provided as part of Udacity's Predictive Analytics for Business Nanodegree.

The dataset includes:

- `RoundRoastersTransactions.csv` – Transaction-level data
- `treatment-stores.csv` – Treatment store information
- `round-roaster-stores.csv` – Store-level information

**Data Source:**  
The files are available in the following GitHub repository:

[Udacity Nanodegree Project – Analyzing a Market Test](https://github.com/jychstar/NanoDegreeProject/tree/master/BAND/p5,%20AB%20test%20new%20menu)
